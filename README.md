# KineSolve — 1D Kinematics Calculator

A MATLAB script that solves for unknown motion variables using the four 1D kinematic equations.

## How to Run
1. Open `KineSolve.m` in MATLAB
2. Click **Run** or type `KineSolve` in the Command Window
3. Enter at least 3 known values — type `NaN` for unknowns

## Variables
| Variable | Symbol | Unit |
|----------|--------|------|
| Initial Velocity | v0 | m/s |
| Final Velocity | vf | m/s |
| Acceleration | a | m/s² |
| Time | t | s |
| Displacement | d | m |
